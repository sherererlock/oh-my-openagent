## 什么是 Oh My OpenCode？

**Oh My OpenCode** 是一个强大的 OpenCode 插件，它能将你的 AI 智能体转变为一个完整的开发团队：

- 🤖 **多智能体编排**: Oracle (GPT-5.2), Librarian (Claude), Explore (Grok), Frontend Engineer (Gemini) 等等
- 🔧 **LSP 工具**: 为你的智能体提供完整的 IDE 能力 - 悬停提示、转到定义、查找引用、重命名、代码操作
- 🔍 **AST-Grep**: 支持 25 种语言的结构化代码搜索和替换
- 📚 **内置 MCP**: Context7 用于文档，Exa 用于网络搜索，grep.app 用于 GitHub 代码搜索
- 🔄 **后台智能体**: 像真实的开发团队一样并行运行多个智能体
- 🎯 **Claude Code 兼容性**: 让你现有的 Claude Code 配置无缝工作

智能体说需要什么样的工作。系统 (Harness) 选择正确的模型。`ultrabrain` 现在默认路由到 GPT-5.4 xhigh。您不需要做任何更改。

### 更好地编写代码。基于哈希锚点的编辑

编辑工具带来的问题 (The harness problem) 是真实存在的。大多数智能体失败的原因不是模型，而是编辑工具。

> *"这些工具都没有为模型提供它想要更改的行的稳定、可验证的标识符......它们都依赖于模型重现它已经看到的内容。当它无法重现时——而且它经常无法重现——用户就会指责模型。"*
>
> <br/>- [Can Bölük, The Harness Problem](https://blog.can.ac/2026/02/12/the-harness-problem/)

受 [oh-my-pi](https://github.com/can1357/oh-my-pi) 的启发，我们实现了 **Hashline**。智能体读取的每一行都会带有内容哈希标签：

```
11#VK| function hello() {
22#XJ|   return "world";
33#MB| }
```

智能体通过引用这些标签进行编辑。如果文件自上次读取以来发生了更改，哈希将不匹配，编辑将在损坏发生之前被拒绝。没有空白重现。没有过期行错误。

Grok Code Fast 1: 成功率从 **6.7% → 68.3%**。仅仅因为改变了编辑工具。

```
├── src/
│   ├── AGENTS.md          ← src 特定上下文
│   └── components/
│       └── AGENTS.md      ← 组件特定上下文
```

智能体自动读取相关的上下文。零手动管理。

## 卸载

要移除 oh-my-opencode：

1. **从您的 OpenCode 配置中移除该插件**

   编辑 `~/.config/opencode/opencode.json` (或 `opencode.jsonc`) 并从 `plugin` 数组中移除 `"oh-my-openagent"` 或旧的 `"oh-my-opencode"` 条目：

   ```bash
   # 使用 jq
   jq '.plugin = [.plugin[] | select(. != "oh-my-openagent" and . != "oh-my-opencode")]' \
       ~/.config/opencode/opencode.json > /tmp/oc.json && \
       mv /tmp/oc.json ~/.config/opencode/opencode.json
   ```

2. **移除配置文件 (可选)**

   ```bash
   # 移除兼容性窗口期间识别的插件配置文件
   rm -f ~/.config/opencode/oh-my-openagent.jsonc ~/.config/opencode/oh-my-openagent.json \
         ~/.config/opencode/oh-my-opencode.jsonc ~/.config/opencode/oh-my-opencode.json

   # 移除项目配置 (如果存在)
   rm -f .opencode/oh-my-openagent.jsonc .opencode/oh-my-openagent.json \
         .opencode/oh-my-opencode.jsonc .opencode/oh-my-opencode.json
   ```

3. **验证移除**

   ```bash
   opencode --version
   # 插件应该不再被加载
   ```

- **模型回退**: `fallback_models` 可以在同一个数组中混合纯模型字符串和每个回退对象设置
- **文件提示词**: 在智能体配置中通过 `file://` 支持从文件加载提示词
- **会话恢复**: 从会话错误、上下文窗口限制和 API 失败中自动恢复
- **模型设置**: 智能体与模型的匹配已内置于 [安装指南](docs/guide/installation.md#step-5-understand-your-model-setup)

## 配置

有主见的默认设置，如果你坚持，也是可以调整的。

查看 [配置文档](docs/reference/configuration.md)。

**快速概览：**
- **配置位置**: 兼容层识别 `oh-my-openagent.json[c]` 和旧的 `oh-my-opencode.json[c]` 插件配置文件。现有的安装仍然通常使用旧的基础名称。
- **JSONC 支持**: 支持注释和尾随逗号
- **智能体**: 覆盖任何智能体的模型、温度、提示词和权限
- **内置技能**: `playwright` (浏览器自动化), `git-master` (原子提交)
- **Sisyphus 智能体**: 带有 Prometheus (计划者) 和 Metis (计划顾问) 的主编排者
- **后台任务**: 配置每个提供商/模型的并发限制
- **类别**: 领域特定的任务委派 (`visual`, `business-logic`, 自定义)
- **钩子**: 25+ 个内置钩子，全都可以通过 `disabled_hooks` 配置
- **MCPs**: 内置 websearch (Exa), context7 (文档), grep_app (GitHub 搜索)
- **LSP**: 带有重构工具的完整 LSP 支持
- **实验性功能**: 激进的截断，自动恢复等等
